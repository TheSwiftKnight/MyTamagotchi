# ForkWorld · 轻量同心广场

这是原版全局大屏的轻量 Web 重构版。视觉采用米白手绘六环同心广场。
六圈房区由内向外分别设置 12、16、20、24、28、32 栋房屋，共 132 个
地图入口：空房显示空置状态，已入住房屋显示对应 Agent 世界详情。

## 架构

- 原生 HTML / CSS / JavaScript，无构建步骤。
- 不再依赖 Phaser、EasyStar、Canvas 游戏循环或地图贴图系统。
- 房屋点击热区使用 DOM，不在广场中央渲染 Agent 形象。
- 桌面端和移动端共用同一入口，移动端可拖拽地图查看六圈房区。
- 数据仍由 `js/shared/data.js` 加载，后端不可达时回退 `data/worlds.json`。

## 运行

Mac 可双击 `启动.command`。也可以在本目录执行：

```bash
python3 -m http.server 8200
```

然后打开：

```text
http://localhost:8200/global.html
```

## 目录

```text
global.html                         轻量响应式入口
js/global/light_app.js              DOM 地图与交互
js/shared/data.js                   数据加载和本地回退
js/shared/tokens.js                 共享设计令牌
data/worlds.json                    世界、地标、居民、互访数据
assets/maps/six-ring-commons.png   六环同心广场底图
assets/maps/cottage-marker.png     手绘房屋交互标记
```

## 交互

- 拖拽地图平移
- 滚轮缩放，右下角按钮缩放和复位
- 点击六圈中的任意房屋查看空置状态或 Agent 世界详情
- 巡航按钮依次浏览各世界

## 接入“进入 Agent 世界”

默认点击“进入 Agent 世界”会触发浏览器事件：

```js
window.addEventListener("forkworld:enter-agent-world", (event) => {
  const { world, house } = event.detail;
  // 在这里接入项目路由，例如 router.push(`/world/${world.world_id}`)
});
```

也可以直接替换桥接回调：

```js
window.ForkWorldHouseBridge.enter = ({ world, house }) => {
  // 接入应用路由、原生容器或小程序跳转
};
```
