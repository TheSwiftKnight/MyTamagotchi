# ForkWorld · 世界地图（全局大屏前端）

「每个世界，都是一个人」—— 每位用户的世界围绕中心广场排成环形，使者互访、灵魂连线、自动巡航。

## 怎么运行

### 方式一：双击（Mac，最简单）
双击 **`启动.command`**，浏览器会自动打开地图。关闭弹出的终端窗口即停止。

> 首次双击若提示"无法打开"，右键 → 打开，或在终端执行一次：
> `chmod +x 启动.command`

### 方式二：命令行（任意系统）
在本文件夹里执行：
```bash
python3 -m http.server 8200
```
然后浏览器打开：`http://localhost:8200/global.html?bg=1`

## 说明

- **纯静态站点**，零后端、零构建。任何静态服务器都能托管（http.server / nginx / GitHub Pages 等）。
- **必须通过 http 打开**（不能直接双击 global.html 用 file:// 打开——浏览器会拦截本地图片加载）。
- URL 末尾的 `?bg=1` 是给大屏/投屏用的（窗口不在前台也不卡）；平时可不带。
- **手写字体**（Caveat / 毛笔体）走 Google Fonts CDN，联网更好看；离线会自动回退到楷体，功能不受影响。
- 交互：拖拽平移、滚轮缩放、点世界看详情、10 秒无操作自动巡航；右下角按钮可手动缩放/全景/巡航。

## 目录结构

```
global.html            入口页
js/
  vendor/              Phaser 3.80 + Easystar（已本地化，离线可用）
  shared/              设计令牌 + 数据加载
  global/              地图渲染(paper_map) + 主逻辑(app)
data/
  worlds.json          世界注册表（正式版换成后端 GET /worlds，结构同构）
  sectors.json         地图分区元数据
assets/sprites/         27 张手绘素材（建筑/角色/装饰，透明 PNG）
```

## 换数据 / 接后端

`data/worlds.json` 就是全局图消费的全部数据（世界、地标、使者、互访、灵魂连线）。
把它替换成后端 `GET /worlds` 的返回即可，字段结构保持一致。
`js/global/app.js` 顶部 `FW.loadData(".")` 是唯一数据入口。
