2主控芯片 · Beken BK7258

Beken 面向 AIoT 多媒体的 Wi‑Fi 6 / BLE SoC，双核异构架构。

项目规格 / 说明
内核架构双核 Arm Cortex‑M33 —— AP 核（应用主核，跑 LVGL + ForkWorld app）与 CP 核（协处理，负责显示/触摸等底层驱动）
程序分区primary_ap_app = 3808 KB（AP 核，本项目素材+代码约占 3629KB）
primary_cp_app = 1088 KB（CP 核）
内存片上 SRAM + 外扩 PSRAM（大位图/绘制缓冲驻留 PSRAM）
无线连接Wi‑Fi 6（2.4GHz）+ 低功耗蓝牙 BLE（SDK 具备，本项目离线运行、未启用）
多媒体加速硬件 JPEG 编/解码、硬件 H.264 编码、2D 图形 PPU（缩放/旋转/混合）、音频编解码
主频可配置，最高约 320 MHz
为什么是双核：早期一度误判「只有 1MB 可用」（那是 CP 核的 primary_cp_app）。实际 app 跑在 AP 核，有 3.8MB 程序空间，素材预算才充裕 —— 这也是能把 1.5MB 大地图 + 角色 + 详情卡全部烘焙进固件的前提。

3显示子系统

物理竖屏，软件旋转成横屏使用。

显示参数值
驱动 ICILI9488
尺寸3.5 英寸
原生分辨率320 × 480（竖屏）
呈现分辨率480 × 320（横屏）
像素格式RGB565（16 位）
接口SPI（软件 SPI）
旋转顺时针 90°（ROTATION_90）
显示引脚 (GPIO)脚位
SPI CSX 片选GPIO48
SPI SDA 数据GPIO50
RST 复位GPIO53
背光类型PWM 调光
背光通道PWM7
配置项LCD_35565
方向要点：面板物理是 320×480 竖屏，通过 BOARD_LCD_ROTATION = ROTATION_90 让 LVGL 呈现为 480×320 横屏并顺时针旋转 90°。触摸坐标也要套同款变换 sx = 480 − ny − 1；sy = nx 才对得上。

4触摸子系统

硬件多点、软件栈默认单点，是本项目双指缩放的关键卡点。

项目规格 / 说明
触摸 ICGoodix GT1151（电容式）
多点能力硬件支持 5 点触摸（状态寄存器 0x814E，点坐标 0x814F 起每点 8 字节）
总线I2C · 7 位地址 0x14
I2C 引脚SCL GPIO13 · SDA GPIO15
坐标空间原生 320×480（需软件旋转到 480×320 屏幕坐标）
软件栈现状平台默认编译为单点（TP_SUPPORT_MAX_NUM = 1）→ LVGL 单点指针；多点需自读 tdl_tp_dev_read()

5供电 · 串口 · 烧录

板子通过一颗 CH342 提供双路 USB 串口。

接口 / 节点用途
USB 转串口芯片WCH CH342（双串口）· VID:PID 1a86:55d2
…usbmodem…641接口 1 —— 下载 / 控制口（DTR/RTS 接芯片复位脚，用于进下载模式）
…usbmodem…643接口 3 —— 日志口 / 串口控制台，波特率 460800
供电USB Type‑C 供电
烧录方式纯软件进下载模式（DTR/RTS 脉冲），无需按板载按钮
# 一条命令进下载模式并覆盖烧录（tyutool）
tyutool reset -d t5ai -p /dev/cu.usbmodem…641          # t5ai 下载脉冲
tyutool write -d t5   -p /dev/cu.usbmodem…641 -b 921600 -f 固件_QIO.bin
踩坑点：复位类型必须是 -d t5ai（不是默认的 bk7231n），且要在 641 口操作；日志口 643 的波特率是 460800（不是常见的 115200）。
