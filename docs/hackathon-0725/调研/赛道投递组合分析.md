## 一、推荐投递组合(6 赛道)

### 1️⃣ 灵光「见自己」—— 主报赛道

- **官方要求**(视觉图+群内 10:26 官方说明):为自己 Vibe;唯一硬性要求 = 最终产出**灵光闪应用**;可以用熟悉工具开发、做完部署到灵光;软硬件结合 demo 可以
- **我们的角度**:「你的世界就是你的自我介绍」就是"为自己 Vibe"的终极形态——不是为别人解决痛点,是把自己封存进一个世界。官方示例"AI 无限流/人生模拟器"和我们同构
- **要做的事**:建世界 H5 + 世界生成动画打包部署成灵光闪应用(render.alipay.com 部署工具);游记卡片在灵光里可交互体验
- **结合 generative_agents**:reverie 内容工厂让世界"真的活过"——"先打动自己"的佐证:你围观自己的世界,就像围观另一个自己
- **成本**:中(部署适配半天);**必投**

### 2️⃣ 清闲 LiberNovo「Desktop Daemon」—— 主报赛道

- **官方要求**:桌面常驻精灵;"Agent 最好的家不是云,是离你最近、一直醒着的小主机";**赛道直接送你这台机器(归你所有)**
- **我们的角度**:硬件宠物 = 桌面常驻精灵的实体形态:24 小时醒着、有访客来你世界时亮灯、灵魂契合时呼吸。它不是工具,是"替你守着你的世界"的精灵
- **要做的事**:领到小主机后,把云端服务/世界渲染跑在它上面,现场演示"精灵住在这台机器里"
- **结合 generative_agents**:reverie 引擎跑在这台小主机上持续模拟你的世界——"一直醒着"不再是比喻,你的世界真的 24 小时在运转
- **成本**:低-中;**必投**

### 3️⃣ 小红书「Build in Public」—— 传播赛道

- **官方要求**(视觉图原文):① 项目在 AdventureX 期间开发、具备可现场演示的原型;② **Build in Public 公开发布记录开发过程**(开发记录/踩坑/改进的方向、深夜的灵感、第一季用户反馈);③ 落地小红书潜力——能在小红书生态被使用/传播/商业化(内容/社区/直播/开店/广告/商单);④ 软硬件不限
- **我们的角度**:游记卡片 + 契合度就是天然的小红书内容("测测你和 TA 的灵魂契合度"是平台验证过的爆款模板);世界生成动画是现成的短视频素材;主提交本来就要求发小红书笔记——**零额外成本**
- **要做的事**:R5 每天发 1-2 条开发笔记;设计上把游记卡片做成"适合截图分享"的版式
- **成本**:极低;**必投**

### 4️⃣ Qoder「一个人 = 一支工程团队」—— 工具赛道

- **官方要求**:用 Qoder 完成编程开发即可参赛,无人数限制;**评审时需讲清哪部分工作由 Qoder 完成**(群公告);奖池 ¥40,000 全场最大
- **我们的角度**:四人团队用 Qoder 补齐人力——前端世界渲染、固件、文档都有 Qoder 参与;评审时按模块讲清楚分工
- **要做的事**:把日常开发切到 Qoder(国际版,关 VPN);保留使用记录
- **成本**:极低(只换开发工具);**必投**

### 5️⃣ Superun「Context to Code · 不比代码,比谁离问题最近」—— 叙事赛道

- **官方要求**(视觉图原文):**要求使用 Superun 作为构建应用主体逻辑的核心工具之一**;最终成果形式不限(AI Agent/Workflow/Web 应用等);项目应来自真实存在、反复发生的问题;"Context 不一定来自职业,你每天生活的世界,就是你的 Context"
- **我们的角度**:这句话简直为我们写的——"你每天生活的世界就是你的 Context"= 你的世界就是你的自我介绍。陌生人社交破冰是最高频的真实痛点;"灵魂契合度"就是 Context 的语义计算
- **要做的事**:用 Superun 搭建世界生成/互访的某个环节(比如画像解析→WorldJSON 的 workflow),能说清"主体逻辑之一"即可;credits 三轮(200→2000→无限)
- **成本**:低;**必投**

### 6️⃣ Photon「消息即界面:给你的 Agent 一个手机号」—— 第六赛道(新发现,替换原备选)

- **官方要求**(视觉图原文):围绕"消息即界面"的 Agent 产品——你的 Agent 拥有手机号之后,能主动发消息、首次参与对话;iMessage/WhatsApp/Telegram/Discord/SMS/RCS 全通道;Photon 提供免费 Spectrum API
- **我们的角度**:**使者出访回来,主动给你发短信**——"我从他的世界回来了,想听听我见到了什么吗?"这是游记最自然的触达渠道,比 H5 推送更有"使者是活的"的感觉;世界留言墙 = 给世界发条短信
- **要做的事**:游记生成后调 Spectrum API 发一条短信/iMessage;demo 时评委手机直接收到——**这会是评委记得住的瞬间**
- **成本**:低(一次 API 接入);**建议投**

## 五、主题选择(已补齐:8bit / PAWN / .xyz / Kaleidoscope / Reverse)

五个主题已从终极指南获取(开幕式视频已下载至 `赛道/theme_*.mp4`,抽帧在 `赛道/theme_frames/`):

| 主题 | 视频内容 | 与我们的契合 |
|---|---|---|
| **Kaleidoscope 万花筒** | 棱镜/万花筒碎晶 | ★★★ 推荐主选:每个人的世界是灵魂的一个切面,千万个世界组成万花筒;两个世界的契合=花纹的对齐 |
| **8bit** | 像素 JRPG/SFC 卡带 | ★★★ 备选主选:我们的世界渲染就是 32×32 像素风(与斯坦福 demo 同规格),"像素世界里住着你的分身" |
| **Reverse 反转** | 楚门的世界帆船片段 | ★★ 可讲:自我介绍的反转——不是你介绍自己,是你的世界替你介绍;社交的反转——agent 替你先走一遍 |
| **PAWN 棋子** | 黑白战争/人群洪流 | ★ 可讲但偏:不做棋子做自己,弱于"见自己"叙事 |
| **.xyz** | 老虎机滚域名后缀 | ★ 可讲:世界=你的个人域名/互联网自留地,偏隐喻 |

**建议:主选 Kaleidoscope**(叙事:"人不是一句话能概括的——万花筒从不只给你看一面。我们让每个人把自己的一面封进一个世界,两个世界碰一碰,花纹对齐的那一刻就是灵魂契合"),**备选 8bit**(视觉叙事,渲染风格天然扣题)。主题评判标准=创意/技术复杂性/社会影响力,我们的"生成式智能体引擎做真人社交"三点全占。
