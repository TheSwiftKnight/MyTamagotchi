## 一、产品定义

### 1.1 一句话

**你不是主角，你是你的 AI 宠物的经纪人**——它在虚拟小镇里替你社交、发帖、涨粉；当你和另一个人碰一碰，两只宠物先聊，聊出结果才轮到你们开口。

### 1.2 世界观（来自 7/22 下午讨论的收敛）

- **宠物 = 明星**：有 IP 形象（圆乎乎、像素风、萌系简洁），住在虚拟小镇里，自主走动、串门、聊天、发帖、维护「粉丝」
- **用户 = 经纪人**：围观自己的明星在小镇里干了什么、和谁聊了什么，可以下场干预；宠物发的帖子内容来自主人的画像与近况
- **硬件 = 明星的「实体分身」**：桌面板子/电子屏形态，宠物在屏上蹦跶，灯光是它的情绪；碰一碰是两个明星的「线下同框」

### 1.3 三支柱（讨论定案 × 调研背书）

| 支柱 | 承载物 | 调研背书 |
|---|---|---|
| **好玩** | Agent 小镇：像素地图、agent 自主社交、发帖墙 | Moltbook 150 万 agent 被 Meta 收购证明「围观 agent 社交」有真需求；AdventureX 获奖公式「新奇有趣」 |
| **实用** | 碰一碰交友：两只宠物先聊 → 汇报共同点与开场白 | Swapcard 900 万样本：无 AI 时 66–68% 连接请求无回应；数字名片赛道全部困在「交换一次就没下文」 |
| **可展示** | 硬件板子：屏幕 + 灯光 + 实体互动 | AdventureX 摊位制评审下实体压倒纯 App（2024–2025 获奖名单实证）；友念以更简单的形态拿过第一名 |

### 1.4 与友念（2025 第一名）的关系——答辩必讲

友念给你一个光信号说「他和你是同类」；我们给你一份两只宠物已经聊完的对话报告，外加一整个它们生活的世界。**主动对标，不回避。**

### 1.5 候选名（现场定）

碰崽 / 星崽 / 经纪喵 / Mooch —— 原则：两个字内可爱、能当动词用（「来碰一个」）。

## 二、系统架构

```
[NTAG213 贴纸/硬件背贴] --NFC 碰一碰--> [对方设备读 ID]
        |                                    |
        v                                    v
[手机扫码 H5（微信内）] <--WebSocket--> [云端服务] <--MQTT--> [硬件板子 M5Dial]
        |                                    |                    (屏显宠物 + WS2812 灯环)
        v                                    v
[画像构建: 主页URL → Jina Reader → LLM 结构化]   [Agent 编排: 两次 LLM 调用 + JSON]
                                             |
                                             v
                                  [Agent 小镇前端: AI Town fork (Convex+PixiJS)
                                   或 Phaser 3 自建像素地图]
```

**五条铁律**（全部来自调研硬结论，答辩被问就按这个口径）：

1. NFC 只做触发（传 ID），数据走云端——微信/支付宝「碰一下」同款架构，别说「离线 agent 对话」
2. Agent 层不上框架：两次裸 LLM 调用 + `response_format: json_object`，一次产出对话稿 + 摘要 + 硬件指令
3. 设备互发现用 ESP-NOW 广播（1–10ms、锁定冷门信道、3 连发去重），不用 BLE 扫描
4. iOS 小程序 HCE 是死路 → 全平台统一「硬件屏显二维码 → 微信扫码 → H5」
5. 演示内容全部预生成缓存，现场只做「拉取」；三级降级兜底（见第六节）

## 三、功能清单（P0 做不完 = 项目失败；P1 锦上添花；P2 只进 PPT）

### P0（Demo 生死线）

- [ ] 扫码建档：贴个人主页 URL → Jina Reader 清洗 → LLM 抽取 `[职业/兴趣/性格/近况]` JSON → Redis
- [ ] 碰一碰：NFC 读取对方 ID → 云端拉起两只宠物的（预生成）对话
- [ ] 汇报卡片：H5 展示对话摘要 +「你们值得开口的那句话」
- [ ] 硬件显影：两台板子同频呼吸灯 + 轻震 + 屏上宠物蹦跳动画（匹配/普通/失败三套本地固化）
- [ ] Agent 小镇 v0：一张像素小镇地图，≥6 只宠物走动 + 头顶对话气泡（内容可预生成），点击宠物看对话记录
- [ ] IP 形象：1 只主宠物 3 视图 + 2 套配色，能贴到硬件屏和小镇里

### P1（有余力再上，每个都独立可裁）

- [ ] 发帖墙：宠物以「代理人」口吻替主人发帖，通讯录式后台界面（数据化视图）
- [ ] 手势双向确认：两人同时比 ✌️ 才亮同频灯（CV 现成模块，只做手势不做人脸）
- [ ] 在场感知：ESP-NOW 广播「谁在附近」→ 摊位大屏社交星图（谁和谁碰过、部落聚类）
- [ ] 今日复盘：「你今天碰了 N 人，3 个值得回访 + 为什么 + 开场白」

### P2（只写进 PPT 的未来篇）

- 碰一碰「生崽」（两 agent 杂交生成合体宠物，遗传算法背景可讲）
- 小镇进阶为「会场社会模拟器」（黑镜叙事）
- UWB 找人指向、PSI 隐私求交（讲 Apple/Signal 先例）、TEE 机密计算

## 八、风险与红线（速查）

- 🔴 **被指友念 2.0** → 开场主动对标，讲清增量（对话内容 + 小镇 + 群体）
- 🔴 **现场翻车** → Day 4 全天防翻车 + 三级降级 + 备份视频
- 🔴 **破冰内容尬/冒犯** → 白名单话题沙盒；只发「入场券」不说破敏感共同点；尴尬时宠物背锅动画
- 🟡 **技术叙事被问穿** → 口径：「近场做发现与握手，智能在云端」；别提「离线 agent 对话」「NFC 传数据」
- 🟡 **隐私质疑** → 一次一授权（碰=同意）、无常开麦克风摄像头、画像阅后即焚；量产路径讲 PSI/TEE
- 🟡 **小镇内容无聊/重复** → 预生成剧本池 + 事件驱动（不做心跳轮询），控制 LLM 成本
- ⚪ **评审随机性** → 四类赛道全投
