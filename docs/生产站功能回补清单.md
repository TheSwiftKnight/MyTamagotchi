# 生产站 → 当前分支 功能回补清单

> 生成于 2026-07-25。基准：生产站 `agentland.throughtheglass.art`
> （跑的是 `origin/codex/agentland-unified-plaza-20260724`，团队公认「功能最齐全」的那版）
> 目标分支：`feature/qr-pair`（含 `origin/main` 的后端对齐 + 本轮修复）

## 为什么会缺

两条线**朝不同方向**分叉，谁都不是另一方的超集：

- **codex（章程 / 生产站）**：统一同心镇广场素材、`Agent Skills` 成长档案页、
  首页 World Residents 卡片条。数据走 `server/world-engine.mjs`（Node，:8787），
  **没有接 FastAPI**。
- **main（Kai）**：`98757b7 feat: wire plaza/agents/skills/inventory UI to FastAPI backend`
  把前端接到了 FastAPI，同时把 App.tsx 从约 1 万行重构到 6694 行，
  **顺带删掉了上面那些页面**；新增了 `conversePair`/`converseLine`（广场对谈，接
  `/api/plaza/converse`）与链上广场。

所以回补的总原则是：**UI 取 codex 的完整形态，数据一律改接 FastAPI（:8000），
并保留 main 与本轮的新增功能**。

## 缺失项清单

### A. `Skills` 标签页 —— Agent 成长档案（最大缺口）

| 项 | 内容 |
|---|---|
| 生产站位置 | 顶部第二个标签 `Skills`（当前分支这个位置是 `Agents`） |
| 源码 | codex `frontends/mobile/src/app/App.tsx` **7743–8247 行**，函数 `AgentGrowthScreen({ sceneControl })` |
| 当前状态 | **完全删除**，`Agent Skills` / `GROWTH PROFILE` / `SKILL DECK` / `SELF EVOLUTION` 等字符串在当前 App.tsx 中一个都不存在 |

页面构成（按生产站实测）：

1. 顶部小标 `MY AGENT · GROWTH PROFILE`，主标题 `Agent Skills`，
   副文案「看看它正在成为谁，以及它刚刚学会了什么。」
2. 右上状态胶囊「自主进化中」（后端不可用时降级为「使用本地成长档案」）
3. agent 选择条：横向卡片（`Dotti LV.14` / `Miko LV.12` / `Shutter LV.10` …），
   带形象图与等级
4. 选中 agent 的档案卡：形象、名字、英文角色名（如 `Training Watchdog`）、
   人格引言、特质标签（专注 / 耐心 / 安全优先）
5. `SELF EVOLUTION` 进化进度条 + 一段「正在把…整理成可独立加载的方法」说明
6. 三项统计：`MEMORY 超长期记忆` / `BONDS 个稳定关系` / `SKILLS 个能力绑定`
7. `SKILL DECK`：「已加载到 {name} 的能力卡」，标注 `独立加载 · 可升级 · 可回滚`；
   卡片可加载/卸载（codex 里是 `toggleSkillLoad(agentId, skillId)` + `skillLoadouts` state）

**回补时必须改的数据源**（codex 原实现是本地常量 + Node 引擎）：

- agent 列表、形象、人格 → `GET /api/agents`（`backendApi.agents()`）
- 单个 agent 的技能与记忆 → `GET /api/agents/{id}`（`backendApi.agent(id)`，
  返回 `skills[]` 与 `memories[]`）
- 统计数字：MEMORY 用 `memories.length`；SKILLS 用 `skills.length`；
  BONDS 暂用 `kind="pair"` 的记忆条数（配对建立的羁绊）
- 技能增删改 → 本轮已补的 `PATCH/DELETE /api/agents/{id}/skills/{skill_id}`
- **不要**引入 codex 的 `worldApi.getAgentConversation` / `chatWithAgent`，
  那两个只有 :8787 的 Node 引擎实现，FastAPI 没有

### B. 首页 `World Residents` 卡片条

| 项 | 内容 |
|---|---|
| 源码 | codex App.tsx **1817–1825 行**附近 |
| 形态 | 小标题 `World Residents` + 副文「小小物件，也有鲜明人格」+ 右侧 `查看全部 →`；下方横向滚动的居民卡片（形象 + 名字 + 角色，右上角有状态色点） |
| 当前状态 | 缺失，首页直接从「Agent正在自我进化」跳到世界卡片 |
| 数据源 | `GET /api/agents`，形象用 `agent.image`，角色用 `profile.role` 或 `category` |

### C. 首页头部统计

- 生产站：`19 位智能体 · 7 种skills · 209 段记忆 · 2 位访客`
- 当前：`8 位我的智能体 · 2 位在广场 · 3 个专属世界`
- 回补：改为「智能体数 / skill 种类 / 记忆总数 / 访客数」四项，
  数据取自 `GET /api/agents` 聚合与 `GET /api/skills`

### D. 标签栏

- 生产站：`Scene ▾ | Skills | Plaza | 链上广场`
- 当前：`Scene ▾ | Agents | Plaza | 链上广场`
- 回补策略：**两个都要**。`Skills` 回补为成长档案页；当前的 `Agents`
  目录页是 main 新增且已接后端（还含本轮加的技能就地改名/删除），不要删。
  建议标签栏改为 `Scene ▾ | Agents | Skills | Plaza | 链上广场`，
  或把 Agents 目录并入 Skills 页的一个子分段。

## 必须保住的既有功能（回补时不得回退）

| 功能 | 位置 | 说明 |
|---|---|---|
| 广场对谈连结与台词 | `ConcentricPlazaMap.tsx` 的 `conversePair` / `converseLine` | 接 `/api/plaza/converse`，是「接了后端」的核心演示点 |

| 链上广场 | `ChainPlazaScreen.tsx` | main 新增，codex 也有，保留 |

## 验收标准

1. `npx tsc --noEmit` 无错误
2. `Skills` 标签能列出后端真实的 11 个 agent，选中任一个能看到它**真实的**
   技能与记忆条数（不是写死的 Dotti/Miko/Shutter 假数据）
3. 首页 World Residents 显示后端真实 agent，形象图能加载
4. 广场仍是 59 栋贴合的热区，对谈功能仍在
5. 无头浏览器全新加载零 HTTP 错误
